# Research Notes

Pre-writing research for luchini.nyc posts: one file per planned post, named
after the planned post file (`YYYY-MM-DD-slug.md`) so the note and the
eventual post in `resources/templates/md/posts/` stay paired.

These notes are created and maintained through the `luchini-writing-research`
skill (`../../.agents/skills/luchini-writing-research/`). They are working
documents — evidence, sources, yardstick candidates, open questions — never
prose for publication. Voice and drafting conventions live in
`../writing-style/`.
