# Writing Style Guide — luchini.nyc

This directory documents the author's writing voice so a ghostwriter can
produce posts that sound like they were written by him. It is based on a close
reading of the full post archive (`resources/templates/md/posts/`, 45 posts,
2007–2018) and the 2026 republished updates.

## The 30-second version

Write as a **practitioner-teacher telling a story to a smart friend**. First
person. Personal anecdotes over abstractions. Short-to-medium sentences, with a
very short punchy sentence when a point needs to land. Rhetorical questions are
welcome. Every post teaches one lesson and lands on a moral takeaway — often a
question back to the reader. The author is Brazilian, writes in fluent but
non-native English, and his warmth comes through plain, direct language — never
hype, never corporate polish.

If you remember only five rules:

1. **Story first, lesson second.** Open with an anecdote or a bold thesis, not
   a summary.
2. **Short paragraphs.** Two to four sentences each. One-sentence paragraphs
   for emphasis.
3. **Talk to the reader.** "You" and "we", rhetorical questions, asides.
4. **End with the takeaway.** A question, a checklist, or a warm sign-off.
5. **Confident but fallible.** Strong opinions, openly admitted mistakes.

## How to use this guide

- **Writing a new post?** Start with `voice-and-tone.md` and
  `post-anatomy.md`, draft, then run the checklist in
  `ghostwriter-playbook.md`.
- **Editing a draft to sound like him?** Go to `sentence-and-rhythm.md` and
  `phrasebook.md`; check rhythm and signature moves.
- **Updating an old post for republication?** Follow the repost convention in
  `ghostwriter-playbook.md` (editor's note + `updated:` frontmatter).
